# 项目长期记忆

## 工作范围约定（重要）

- 本项目只改**前端**部分，主要是**样式**调整。
- 不修改、不涉及后端部分（`cmd`、`internal`、Go API 等）。
- 前端代码位于 `web/`（Taro + React + TypeScript）。
- **没有用户明确改动指令时，不擅自修改代码**（可先观察/排查/说明，但改动前需得到明确指令）。

## UI 配色偏好（重要）

- 小程序整体是**蓝紫冷色系**的温馨可爱宠物风（背景房间插画 bg1.png 蓝紫调、logo「凑凑」深蓝主色）。
- **不要用橙色/暖橙/蜜桃色系**（用户明确多次强调"很奇怪、割裂"）。
- **不要用深色**（深蓝被评价"丑、不搭"）。
- 按钮宜用**中等亮度的蓝色渐变 + 白字 + 大圆角胶囊**（圆角 999px）。
- onboarding 页按钮已统一为「白玻璃 + 蓝边框」体系：主按钮 `4rpx solid rgba(94,139,200,0.85)` 蓝边 + `rgba(255,255,255,0.55)` 玻璃底 + backdrop blur + 深蓝字 `#4A6489` + 胶囊圆角；弱化按钮同色系降透明度（3rpx，0.55/0.45）。新按钮照此体系加。注意：2rpx 细边框在浅色背景上几乎看不见，主按钮边框至少 4rpx + 高不透明度才明显。
- 气泡用白底 + 蓝紫描边 + 深蓝字。
- 全局样式 `app.scss` 有两条会影响页面按钮的规则：
  1. 第 14-16 行 `button { border-radius: var(--btn-radius) !important; }` —— 带 !important，会把所有按钮圆角压成小圆角。页面内自定义圆角必须也加 `!important`（同 important 时类选择器优先级高于元素选择器）。
  2. 第 91-100 行 `.profile-onboarding button` 等通用玻璃按钮规则（specificity 0,1,1），会覆盖页面内同名类（0,1,0）的按钮样式，需要用 `:not()` 或提高优先级。
