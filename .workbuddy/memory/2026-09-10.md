## 按钮直角问题的真正根因（重要）

```scss
button {
  border-radius: var(--btn-radius) !important;
}
```

这条全局规则带 `!important`，把页面里所有自定义按钮圆角强制压成 `--btn-radius`（小圆角）。之前一直误判为「缓存问题」。

- 头像按钮 50% 原本就有 !important（136 行）。

教训：本项目中按钮样式「不生效/被改样」有两条全局规则要排查（均已写入 MEMORY.md）：

2. `app.scss:91-100` 的 `.profile-onboarding button` 等通用玻璃规则（压背景/边框/字色）
