# 红旗症状表

本文供人工审核和补充，与代码表一一对应。**代码是唯一事实源**：
`internal/platform/safety/redflags.go`，表版本 `ask-red-flags-v1`。

用途：

- Runtime 的确定性风险规则命中任一红旗即升级为 `red`，直接给出就医提示，不交给模型判断。
- 知识库用同一份词表判断提问是否含红旗信号，并据此强制保留带升级条件的知识条目。

收录标准：只收录「需要立即联系宠物医院」的信号。普通观察项、护理建议放在知识条目里，
不要放进这张表；不确定时先不收，宁可漏也不误报。

## 审核范围说明

- 短语是用户原话里可能出现的说法；过短的通用词（例如单独的「吐」「血」「发烧」）会误报，因此没有收录。
- 匹配会忽略否定和假设表达，例如「没有呼吸困难」「如果抽搐怎么办」「如何判断呼吸困难」不会升级为 `red`。
- 知识正文抽取升级条件时按字面判断，不套用上面的否定规则。
- `code` 发布后不要改名，改名会让历史 Run 的 `trigger_code` 失去对应。
- 条目按表中顺序匹配，越靠前越先命中并成为 `trigger_code`；已上线条目保持在前。
